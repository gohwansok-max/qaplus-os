# Predictions Journal (예측 저널)

> 김이사의 전략 판단을 예측으로 기록하고, 결과를 검증하여 판단력을 교정합니다.
> **예측 없이는 개선도 없다.** 측정되지 않는 판단은 발전하지 않습니다.
>
> 6개월 운영하면 **"내 김이사의 적중률 N%"**가 데이터로 나옵니다.

---

## 사용법

모든 전략 제안에 아래 4가지가 포함되어야 합니다:

1. **예측**: 구체적, 측정 가능한 1문장
2. **확신도**: 0~100%
3. **근거**: 왜 이렇게 예측하는가 (데이터/논리)
4. **검증일**: 언제 결과를 확인할 것인가 (YYYY-MM-DD)

검증일이 지나면 **결과**와 **오차 분석**을 추가합니다.

### [P-001] 2026-08-24 — 썸네일 숫자형 우위 가설

  2. 타겟(QA/QC 실무자)은 "바로 쓸 수 있는 정보"를 찾는 검색 의도가 강함
  3. 단, 구독자 50명 규모에서는 통계적 유의성 확보 어려움 (샘플 부족)

- **검증일**: 2026-09-24 (1개월 운영 후)

  3. 배치 촬영은 세팅/조명 반복 비용을 1회로 압축
  4. 단, 현재 소요 시간 실측치 미확보 → 정확한 기준선 필요 (CEO 확인 필요)

## 오차 패턴 분석 (누적 후 작성)

### 주의할 편향
- **과신 편향**: 확신도를 실제보다 높게 잡는 경향
- **앵커링 편향**: 첫 번째 데이터에 과도하게 의존
- **낙관 편향**: 긍정적 결과를 더 높게 예측
- **생존자 편향**: 실패 사례 무시하고 성공 사례만 참조

## 기록 템플릿

```markdown
### [P-번호] YYYY-MM-DD — 예측 제목

- **예측**: (구체적, 측정 가능한 1문장)
- **확신도**: N% (확신합니다 / 가설입니다 / 직감입니다)
- **근거**:
  1. (데이터/논리)
  2. ...
- **검증일**: YYYY-MM-DD
- **결과**: (검증 후 — 적중/빗나감/폐기)
- **오차 분석**: (틀렸다면 왜 틀렸는가)
```

### 폐기 규칙

**전제 조건 미충족**으로 검증 불가능한 경우 `폐기` 처리. 이때도 **왜 전제가 깨졌는지** 기록 (예측 자체의 오류인지 실행 문제인지 구분).
