# 릴스 제작

## 목적
AI 활용 주제 릴스를 일관된 후킹·길이·CTA 기준으로 빠르게 생산한다.

## 프로세스
1. 주제 선정 → 타겟(왕초보/직장인/대표/프리랜서 중 1) 명시
2. 후킹 3안 작성 → 가장 강한 1안 선택 (질문/충격/반전 중 하나)
3. 30~40초 대본 작성 (인사·서론 금지, 모든 줄이 인사이트)
4. 캡션 + 제목 + 해시태그 + CTA 1개 작성
5. 톤앤매너 3원칙 + 금지 행동 5가지 체크

## 품질 기준
- [ ] 첫 문장 3초 내 후킹 (질문/충격/반전 중 하나)
- [ ] 전체 길이 30~40초
- [ ] 모든 줄이 인사이트 (filler 금지)
- [ ] CTA 정확히 1개
- [ ] 검증 안 된 AI 정보 단정 0건 (출처 또는 "확인 필요" 표기)
- [ ] 경쟁사·경쟁 툴 비방 0건
