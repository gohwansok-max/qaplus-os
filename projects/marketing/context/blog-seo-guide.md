# QA+ 블로그 SEO 가이드 (Blogger/Blogspot 대상, 2026)

> `blog-researcher`/`blog-writer` 서브에이전트가 참고하는 SEO 체크리스트.
> 대상 플랫폼은 Google Blogger(blogspot.com) — 네이버 블로그가 아님에 주의.

## 1. 제목/URL

- 타겟 키워드를 제목(H1) 맨 앞쪽에 배치
- 제목 60자 이내 (넘으면 검색결과에서 "…"로 잘림)
- URL 슬러그는 짧고 키워드 중심, 불용어 제거 (Blogger는 첫 발행 시 제목 기반으로 슬러그 자동 생성 — 발행 전에 확인)
- 한 번 색인된 URL은 가급적 변경하지 않는다 (링크 자산 손실 방지)

## 2. 본문 구조

- H1은 글 제목 하나만, 소제목은 H2/H3로 계층화
- 타겟 키워드와 연관 키워드를 소제목·본문에 자연스럽게 분산 (키워드 스터핑 금지 — Google이 부자연스러운 밀도를 감점)
- 얕은 내용(thin content)은 색인은 되어도 순위가 밀린다 — 주제를 실제로 깊이 다룰 것 (블로그 스타일가이드의 "사례" 섹션이 이 역할)

## 3. 이미지

- 파일명에 키워드 포함 (예: `ccp-일지-교차검증.jpg` 대신 영문 키워드 슬러그 권장: `ccp-log-cross-check.jpg`)
- alt 텍스트 필수 — 이미지가 무엇을 보여주는지 간결히 서술
- Blogger는 이미지 자동 압축을 하지 않으므로 업로드 전 적정 해상도(가로 1200px 내외)로 조정

## 4. 모바일/기술 SEO

- Blogger 기본 반응형 템플릿 사용 확인 (모바일 우선 색인 대응)
- 페이지 로딩 속도에 영향 주는 과도한 고화질 이미지 다수 삽입 지양

## 5. 신선도/일관성

- 매일 또는 정기적으로 발행 빈도를 유지하는 것이 장기적으로 순위에 유리
- 발행 후에도 필요 시 업데이트하고 "최종 수정일" 개념을 유지 (신선도 신호)

## 6. 링크

- 같은 블로그 내 관련 글 상호 링크 (내부 링킹)
- 가능하면 신뢰할 수 있는 외부 출처(식품안전나라, 식약처 고시 원문 등) 링크로 근거 보강

## 7. Search Console

- Google Search Console에 사이트 등록 및 사이트맵 제출 여부는 사용자가 직접 확인해야 함 (계정 접근 필요 — 자동화 불가 영역)
