# 유튜브 대본 작성 스킬

## 목적
유튜브 영상 제작 시간을 단축하고, 일관된 품질의 대본을 생성한다.
20년 경력 전문성을 보여주면서도 초보자가 이해하기 쉬운 콘텐츠를 만든다.

## 입력
- 주제: HACCP/FSSC22000 관련 주제 (예: "CCP 설정 방법", "FSSC 인증 준비")
- 타겟: QA/QC 초보자 또는 HACCP 팀장
- 영상 길이: 3~5분

## 프로세스

### 1단계: 구조 설계
```
00:00-00:10 (10초) — 후킹 (질문 or 충격 or 숫자)
00:10-00:30 (20초) — 문제 정의 + 왜 중요한가
00:30-03:00 (2분30초) — 핵심 내용 3가지
03:00-03:30 (30초) — 정리 + CTA
```

### 2단계: 대본 작성
- CEO 톤앤매너 3원칙 준수 (`context/ceo-persona.md` 참조)
- 전문용어는 반드시 "쉽게 말하면" 추가
- 20년 경력 자연스럽게 녹이기
- 출처 명시 (화면 자막용)

### 3단계: 최적화 요소 추가
- 썸네일 문구 제안 (핵심 키워드 + 숫자)
- 제목 3가지 옵션
- 설명란 텍스트 (SEO 키워드 포함)
- 고정댓글 안내문

## 출력 형식

```markdown
# [주제] 유튜브 대본

## 제목 옵션
1. [옵션1 — 숫자형]
2. [옵션2 — 질문형]
3. [옵션3 — 베네핏형]

## 썸네일 문구
"[핵심 키워드 + 숫자]"

## 대본

### 00:00-00:10 후킹
[대본]

### 00:10-00:30 문제 정의
[대본]

### 00:30-03:00 핵심 내용
**1. [첫 번째 포인트]**
[대본]
*출처: [출처 명시]*

**2. [두 번째 포인트]**
[대본]
*출처: [출처 명시]*

**3. [세 번째 포인트]**
[대본]
*출처: [출처 명시]*

### 03:00-03:30 정리 + CTA
[대본]

## 설명란
[SEO 키워드 포함 설명 + 오픈채팅방 링크 + 컨설팅 안내]

## 고정댓글
[CTA + 채팅방 초대]
```

## 품질 기준 (반드시 숫자로!)

| ID | 기준 | 합격 조건 | 가중치 |
|:---|:---|:---|:---:|
| Y1 | 첫 10초 후킹 | 질문/충격/숫자 중 1개 포함 | 필수 |
| Y2 | 영상 길이 | 3~5분 분량 (대본 900~1500자) | 필수 |
| Y3 | 전문용어 풀이 | 모든 전문용어 뒤에 "쉽게 말하면" 추가 | 필수 |
| Y4 | 출처 명시 | 핵심 내용 3가지 모두 출처 표기 | 필수 |
| Y5 | CTA | 마지막에 오픈채팅방 or 컨설팅 안내 1개 | 필수 |
| Y6 | 톤앤매너 | CEO 페르소나 3원칙 준수 | 필수 |
| Y7 | filler 제거 | "안녕하세요", "감사합니다" 없음 | 필수 |

## 예시

### 입력
주제: "CCP가 뭔지 3분 안에 이해하기"
타겟: QA/QC 초보자

### 출력
```
# CCP 3분 완전정복 유튜브 대본

## 제목 옵션
1. CCP 3분 완전정복 | 20년 경력이 알려주는 핵심 3가지
2. HACCP 인증 탈락 1순위? CCP 몰라서 그래요
3. CCP만 알면 인증 80% 통과 | 실무에서 바로 쓰는 노하우

## 썸네일 문구
"CCP 핵심 3가지"

## 대본

### 00:00-00:10 후킹
"HACCP 인증 탈락하는 업체 절반이 이거 몰라서 떨어져요. CCP. 오늘 3분 안에 완전히 이해시켜드릴게요."

### 00:10-00:30 문제 정의
"CCP가 뭔지 아시나요? Critical Control Point. 쉽게 말하면 '여기서 실수하면 식중독 날 수 있는 포인트'예요. 20년 해보니 이거 3가지만 확실히 잡으면 인증은 문제없더라고요."

[... 계속]
```
