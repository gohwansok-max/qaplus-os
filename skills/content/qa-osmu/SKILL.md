# 큐에이플러스 OSMU 콘텐츠 자동 생성 스킬

## 목적
식품 품질관리/HACCP/FSSC22000 관련 실무 주제 1개를 바탕으로, 대표님의 20년 현장 경험과 친근한 선배 톤을 담아 **유튜브 대본 + 블로그 실무 칼럼 + SNS 인포그래픽 구성안**을 일괄 생성하여 제작 시간을 70% 단축한다.

---

## 프로세스

1. **Step 1. 실무 문제 정의 및 법적/기준 출처 매핑**
   - 주제와 관련된 법령(식품위생법, 축산물위생관리법, 식품공전) 또는 인증 기준(HACCP 7원칙, FSSC 22000 V6) 조항 확인
   - 현장에서 자주 발생하는 트러블/지적 사례 1개 결합

2. **Step 2. 큐에이플러스 유튜브 5분 대본 작성**
   - 0~5초: 현장 실무자가 즉시 멈칫할 강렬한 문제 제기 (후킹)
   - 본론: 3단계 실무 해결법 + "쉽게 말하면..." 일상어 해설
   - 결론: 요약 1줄 + 오픈채팅방 질의 안내 (상업적 멘트 배제)

3. **Step 3. 네이버 블로그 실무 칼럼 작성**
   - 검색 키워드 최적화 (제목 + 소제목 3개)
   - 본문: 현장 상황 공감 + 법적 기준표/체크리스트 + 현장 팁

4. **Step 4. 인스타그램 / 오픈채팅 인포그래픽 기획안 작성**
   - 1:1 또는 4:5 카드뉴스 4단 구조 (제목 → 문제점 → 핵심 기준 → 실무 체크포인트)
   - 이미지 생성 AI(ChatGPT / DALL-E / Nano Banana 등) 프롬프트 및 한글 텍스트 배치안

## 품질 기준 (반드시 충족해야 할 정량 기준)

- [ ] **후킹 3초**: 첫 문장에 인사치레 없이 질문/문제 제기 포함
- [ ] **출처 명시**: 관련 법령, 고시, FSSC 기준 최소 1개 이상 명시
- [ ] **유튜브 대본 분량**: 5~7분 분량 (공백 제외 1,200~1,500자 내외)
- [ ] **블로그 분량**: 소제목 3개 이상, 실무 체크리스트 박스 1개 포함
- [ ] **인포그래픽 레이아웃**: 핵심 텍스트가 한눈에 들어오는 4개 비주얼 슬라이드 구성안 포함
- [ ] **톤앤매너**: 존댓말 기반 친근한 선배 톤 ("현장에서 바로 써먹는 팁입니다")
- [ ] **상업적 멘트 제로**: 유료 강의나 컨설팅 유도 문구 0건
