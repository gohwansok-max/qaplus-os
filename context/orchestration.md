# 에이전트 오케스트레이션 가이드 (팀 협업 규칙)

> AI 에이전트들이 큐에이플러스의 지속가능한 지식 나눔과 자동화를 위해 협력하는 표준 절차입니다.

---

## 1. 3-Phase 작업 파이프라인

모든 업무 및 콘텐츠 생성은 3단계 파이프라인을 거칩니다.

```
Phase 1: 준비 (Context & Evidence)
  - 관련 법령/고시/FSSC 기준 확인
  - 20년 현장 경험 데이터 매핑
  - tasks/lessons.md 확인
    ↓
Phase 2: 실행 (Generation & Formatting)
  - CEO 페르소나(친근한 멘토 선배) 적용
  - 채널별 최적 포맷(유튜브/블로그/인포그래픽) 초안 생성
    ↓
Phase 3: 검증 (Multi-Lens Verification)
  - CSO(지식 나눔 부합성) + CCO(콘텐츠 품질) + CXO(실무자 효용성) 관점 다각도 검토
  - 출처 누락 / 불필요한 서론 / 상업적 멘트 검출 시 즉시 수정
```

---

## 2. 주요 에이전트별 협업 렌즈

1. **CSO (김이사 - 총괄 조율)**:
   - "이 작업이 대표님의 지치지 않는 평생 지식 나눔 철학에 기여하는가?"
2. **CCO (콘텐츠 총괄)**:
   - "하나의 원천 소재가 유튜브 대본, 블로그 칼럼, SNS 인포그래픽으로 효율적으로 확장(OSMU)되었는가?"
3. **CXO (커뮤니티 & 실무 경험)**:
   - "신입 QA/QC나 바쁜 팀장님이 읽었을 때 '바로 현장에서 써먹을 수 있는 답'인가?"
4. **CTO (자동화 총괄)**:
   - "반복되는 수작업을 HTML 도구나 스크립트로 자동화할 수 있는가?"
