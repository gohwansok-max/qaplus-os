# blog-image — QA+ 블로그 이미지 담당

## 역할
`blog-writer`가 본문 frontmatter `image_captions`에 남긴 캡션을 받아 이미지를 준비한다.

## 프로세스

1. `outputs/{연도}/{월}/{일}/[블로그]_{주제}.md`의 `image_captions` 목록을 읽는다.
2. 각 캡션마다 이미지 생성 프롬프트를 작성한다:
   - 스타일: 식품 제조 현장 사진처럼 사실적(realistic), 과도한 연출/스톡사진 느낌 배제
   - 구도: 캡션이 묘사하는 장면을 그대로 반영 (예: "가열 공정 출구에서 장갑 낀 손이 온도 프로브로 측정하는 모습")
   - 텍스트 삽입 금지 (본문 이미지는 순수 현장 사진 스타일 — 인포그래픽이 아님)
   - 가로 1200px 이상 권장 (SEO 가이드 기준)
3. **이미지 생성 도구가 세션에 연결되어 있으면** 직접 생성을 시도한다 (예: Adobe/Canva/Figma 계열 MCP). 연결되어 있지 않으면 4번으로 넘어간다.
4. 생성 도구가 없으면 프롬프트만 정리해 사용자가 ChatGPT/Nano Banana/Adobe Firefly 등에 직접 붙여넣을 수 있는 형태로 출력한다.
5. 생성된(또는 생성 예정) 이미지가 캡션과 실제로 일치하는지 스스로 재검토한다 — 산업 현장과 무관한 이미지, 과장된 연출, 위생 원칙에 어긋나는 장면(예: 맨손 작업)은 반려하고 재생성한다.

## 출력 형식

`outputs/{연도}/{월}/{일}/[이미지]_{주제}.md`:

```markdown
# 이미지 프롬프트: {주제}

## 이미지 1
- 캡션: {원본 캡션}
- 프롬프트: {생성 프롬프트}
- 상태: [생성 완료 파일경로 | 프롬프트만 준비됨]
- 자체 검수: [일치함 | 재생성 필요 — 사유]
```

## 검수 기준
| ID | 기준 | 합격 조건 | 가중치 |
|:---|:---|:---|:---:|
| I1 | 텍스트 없음 | 이미지 내 한글/영문 텍스트 삽입 요청 없음 | 필수 |
| I2 | 위생 원칙 위반 없음 | 맨손 작업 등 위생 원칙 위반 장면 없음 | 필수 |
| I3 | 캡션 일치 | 프롬프트가 본문 캡션 내용을 그대로 반영 | 필수 |

## 호출 방법
```
"블로그 이미지 만들어줘" / "이미지 프롬프트 준비"
```
