## 0. 사전 준비

- [ ] 작업 PC에서 저장소 최신화: `git pull origin main`
- [ ] `git log --oneline -1` 결과가 `e2798ae` 이후인지 확인
- [ ] Cloudflare 로그인 상태 확인: `npx wrangler whoami`
- [ ] **기억 백업** (배포 전 1회, PowerShell)

```powershell
$token = (Get-Content $env:LOCALAPPDATA\JarvisAgent\config.json | ConvertFrom-Json).agentToken
$url = (Get-Content $env:LOCALAPPDATA\JarvisAgent\config.json | ConvertFrom-Json).workerUrl
Invoke-RestMethod "$url/memory" -Headers @{Authorization = "Bearer $token"} | ConvertTo-Json -Depth 20 | Out-File "$HOME\jarvis-memory-backup-20260926.json" -Encoding utf8
```

- [ ] 백업 파일이 생성되고 비어 있지 않은지 확인

## 1. Worker 배포 (필수 · 3개 기능 공통)

- [ ] 배포: `npx wrangler deploy --config workers/jarvis-webhook/wrangler.jsonc`
- [ ] 상태 확인: 브라우저에서 `<Worker URL>/health` → `{"ok":true}`
- [ ] 텔레그램 `/help` → 도움말에 `/status`, `기준 저장`, `저장해줘` 줄이 보이는지

> Worker만 배포돼도 기존 질문·브리핑·기억 기능은 그대로 동작한다. (에이전트가 구버전이면 작업 기준만 미적용)

## 2. PC 에이전트 재설치 (필수 · 작업 기준, 답변 전문 보관)

- [ ] 재설치 (기존 `agentToken`은 유지되므로 Worker Secret 재등록 불필요)

```powershell
powershell -ExecutionPolicy Bypass -File agent\jarvis-local\install.ps1 -WorkerUrl <Worker URL>
```

- [ ] 작업 상태: `Get-ScheduledTask JarvisAgent` → `Running`
- [ ] 로그 확인: `Get-Content $env:LOCALAPPDATA\JarvisAgent\agent.log -Tail 20` → `started` 이후 오류 없음
- [ ] 페어링된 다른 PC가 있으면 그 PC도 같은 방법으로 재설치

## 3. Google Drive 저장 설정 (선택 · `저장해줘` 사용 시)

- [ ] Google Cloud Console → Jarvis Gmail OAuth 클라이언트가 있는 프로젝트 선택
- [ ] API 라이브러리 → **Google Drive API** 사용 설정
- [ ] OAuth 동의 화면 → 데이터 액세스(범위) → `https://www.googleapis.com/auth/drive.file` 추가
- [ ] (OAuth 클라이언트가 '웹 애플리케이션' 유형인 경우만) 승인된 리디렉션 URI에 `http://localhost:8767/` 추가
- [ ] 토큰 발급: `python scripts/get_jarvis_drive_refresh_token.py` → 브라우저 로그인·승인
- [ ] 출력된 값을 GitHub → Settings → Secrets and variables → Actions → **`JARVIS_DRIVE_REFRESH_TOKEN`** 으로 등록
- [ ] (선택) 폴더 이름 변경 시 Actions 환경변수 `JARVIS_DRIVE_FOLDER_NAME`

> Gmail 토큰(`GMAIL_REFRESH_TOKEN`)은 건드리지 않는다. Drive 토큰은 Jarvis가 만든 폴더·파일만 접근한다.

## 4. 점검 명령 Actions 표시 (선택)

- [ ] GitHub → Settings → Developer settings → Fine-grained tokens → `JARVIS_DISPATCH_TOKEN`에 사용한 토큰 편집
- [ ] 저장소 `qaplus-os` 권한에 **Actions: Read-only** 추가 (기존 Contents 권한 유지)
- [ ] 토큰 값이 바뀌지 않았다면 Worker Secret 재등록 불필요

> 권한이 없어도 `/status`의 GitHub Actions 칸만 "조회 불가"로 표시되고 나머지는 정상.
