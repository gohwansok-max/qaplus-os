## 요약

텔레그램 봇은 **2개**다. 봇·Worker·Secret이 서로 분리되어 있다.

| 봇 | 용도 | 코드 위치 |
|:---|:---|:---|
| **QA+ 콘텐츠 봇** | 쇼츠 제작, 블로그 검토·발행 | `workers/telegram-webhook/` |
| **Jarvis 개인 비서 봇** | 자유 질문, 메일 브리핑, 기억, 작업 기준, 파일 저장 | `workers/jarvis-webhook/`, `agent/jarvis-local/`, `scripts/jarvis_*.py` |

## 1. QA+ 콘텐츠 봇 (쇼츠·블로그)

| 명령 | 동작 |
|:---|:---|
| `/make [주제]` 또는 `만들어줘: 주제` | 해당 주제로 쇼츠 영상 제작 |
| `/daily`, `오늘`, `오늘영상` | 다음 순번 주제로 쇼츠 제작 |
| 블로그 검토 메시지 **[발행하기]** 버튼 | Blogger 발행 (이미 LIVE인 글은 재발행하지 않음) |
| 블로그 검토 메시지 **[보류]** 버튼 | 임시저장 상태 유지 |
| `/help` | 도움말 |

- 명령은 즉시 접수되고, 실제 작업은 GitHub Actions 실행 대기 후 시작된다.

## 2. Jarvis 개인 비서 봇

### 2-1. 사용 중인 기능 (PR #6~#14, 배포되어 있으면 사용 가능)

| 명령 | 동작 |
|:---|:---|
| 자유 질문 (텍스트) | 질문 성격에 따라 자동 선택: 일반 → Claude / 코드·엑셀 → ChatGPT / 최신 정보 → Gemini(웹 검색). PC가 꺼져 있으면 GitHub Actions(OpenAI API)가 답함 |
| `@claude` / `@gpt` / `@gemini` 로 시작 | 답할 모델 직접 지정 |
| `@all` 로 시작 | 세 모델 답 비교 |
| 음성 메시지 (5분·20MB 이하) | 음성 인식 후 같은 방식으로 처리 |
| `/briefing` 또는 `브리핑` | 최근 24시간 중요 메일 브리핑 (평일 07:30 KST 자동 발송) |
| 브리핑 **[답장 초안 만들기]** 버튼 | Gmail 임시보관함에 초안 생성 (발송은 직접) |
| `/today_tasks`, `오늘 할 일` | 메일 기반 오늘 할 일 |
| `/memory` | 학습한 기억 보기 |
| `기억해: ...` / `기억 수정: ...` | 직접 기억시키기 / 잘못 기억한 것 고치기 (`[품질]`, `[선호]` 등 분류 태그 가능) |
| `/forget_all` | 학습 기억 전체 삭제 (작업 기준은 유지) |
| `/devices` | 연결된 PC 목록·연결 해제 |
| `/help`, `도움말` | 도움말 |

### 2-2. 배포 후 사용 가능한 기능 (PR #5, 2026-09-26 병합)

| 명령 | 동작 | 필요한 배포 작업 |
|:---|:---|:---|
| `/status` 또는 `점검` | PC 에이전트·사용 가능 모델·대기열·기억·Actions 상태 한 번에 확인 | Worker 배포 |
| `기준 저장: 이름` + 줄바꿈 + 본문 | 반복 업무의 답변 규칙 저장 (같은 이름이면 덮어씀) | Worker 배포 |
| `/standards`, `기준 목록` | 저장된 기준 목록 | Worker 배포 |
| `기준 보기: 이름` / `기준 삭제: 이름` | 본문 확인 / 삭제 | Worker 배포 |
| 질문에 기준 이름 또는 `#이름` 포함 (예: "협찬 거절로 답장 써줘") | 저장한 기준대로 답변, 끝에 `기준: 이름` 표시 | Worker 배포 + PC 에이전트 재설치 |
| `저장해줘`, `저장해줘: 제목` | 직전 답변을 Google Drive `Jarvis 저장함`에 md 파일로 저장 후 링크 회신 | Worker 배포 + 에이전트 재설치 + Drive 토큰 등록 |

> 배포 절차: `outputs/2026/09/26/[기타]_자비스_배포_체크리스트.md` 0~3단계

### 2-3. 작업 기준 사용 예

```
기준 저장: 협찬 거절
감사 인사 → 이번에는 어려운 이유 → 다음 기회 제안. 세 문장, 담백하게.
```

→ 이후 `A사 협찬 제안 왔어. 협찬 거절로 답장 써줘` 라고 보내면 위 기준대로 답한다.
